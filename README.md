# MovinderAPI 🎥

MovinderAPI is a Django-based application designed to provide movie recommendations using a hybrid machine learning model. This project leverages TensorFlow for model inference and integrates seamlessly with Hugging Face Spaces.

## Features
- **Movie Recommendations**: Personalized suggestions based on user preferences.
- **Hybrid Model**: Combines collaborative filtering and content-based filtering.
- **Interactive API**: Exposes endpoints for querying recommendations.
- **Dockerized Deployment**: Easily deployable using Docker.

## How to Use
1. **Run the Space**: Click the "Run" button on the Hugging Face Space to start the application.
2. **Interact with the API**: Use the provided endpoints to fetch movie recommendations.
